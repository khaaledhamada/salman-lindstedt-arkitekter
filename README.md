# Salman Lindstedt Arkitekter

Granskningsversion av en enkel presentationswebbplats med introduktion och kontaktuppgifter.

Statisk HTML och CSS. Öppna `index.html` direkt i en webbläsare för att granska lokalt. GitHub Pages publicerar filerna från huvudgrenen.

Logotyp, rutbakgrund och porträtt har tillhandahållits av företaget. Bilder och logotyp omfattas av respektive rättighetsinnehavares rättigheter.
